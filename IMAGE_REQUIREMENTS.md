# Requerimientos de fotografías pendientes

## FOTO-PLANTA-01

**Sección:** Introducción / Nosotros

**Fotografía requerida:** Vista general interior o exterior de una instalación vinculada a recepción, revisión o preparación de productos.

**Orientación recomendada:** Horizontal

**Uso:** Imagen principal editorial para reforzar la operación real de la empresa sin usar fotografía de stock.

---

## FOTO-PLANTA-02

**Sección:** Servicios / Garantía de calidad

**Fotografía requerida:** Mesa, área o estación donde se revise, seleccione o empaque producto antes del envío.

**Orientación recomendada:** Horizontal

**Uso:** Acompañar la explicación del control de calidad y preparación previa al envío.

---

## FOTO-PLANTA-03

**Sección:** Servicios / Logística

**Fotografía requerida:** Productos embalados, cajas, pallets o carga lista para transporte/logística.

**Orientación recomendada:** Horizontal

**Uso:** Representar visualmente la etapa de logística y despacho manteniendo el mismo layout responsive.
